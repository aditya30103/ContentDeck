# Phase 4: Social & Scale — FROZEN

> **Status: FROZEN — 2026-02-27**
>
> The social and scale features in this phase contradict the core product philosophy.
> ContentDeck is a personal retreat, not a platform. A social layer would introduce
> comparison, public performance, and content sourced from others' preferences — all
> of which undermine the "peace with the queue" and "nutritionist, not chef" principles.
>
> **If ContentDeck ever becomes a genuinely multi-user product at scale, revisit this
> phase then. Not before. The philosophy comes first.**
>
> Reference: `docs/plan/philosophy.md` — "What ContentDeck Must Never Become"

---

## Original Plans (for reference)

The following features were planned and are preserved for historical context only.
None should be built while ContentDeck remains a personal tool.

- **4.1 Public Reading Lists** — shareable tag areas, OG tags per list
- **4.2 User Profiles** — reading stats opt-in, pinned collections, follow system
- **4.3 Discover Feed** — trending bookmarks across all users
- **4.4 Collaborative Collections** — shared areas, Supabase Realtime
- **4.5 Weekly Digest Email** — automated weekly email via Resend
- **4.6 Achievements & Gamification** — milestones, streaks, badges

These are not bad ideas. They are the wrong ideas for this product at this stage.
