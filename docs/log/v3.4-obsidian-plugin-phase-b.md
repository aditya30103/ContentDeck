## What shipped

Phase B closes the Reflect→Export loop by letting Obsidian pull bookmarks directly — no
browser tab required. Works on Windows, iPhone, iPad via iCloud sync.

### ContentDeck: `sync-done` edge function

`supabase/functions/sync-done/index.ts`

- **GET `?token=<token>`** — returns all `status='done' AND synced=false` bookmarks for the
  token owner. Joins `bookmark_tags → tag_areas` and flattens `areas` into the response.
- **POST `?token=<token>`** body `{ ids: string[] }` — sets `synced=true` on those bookmark IDs
  (scoped to the token owner's `user_id`).
- Same SHA-256 token auth as `save-bookmark`. Deployed `--no-verify-jwt`.
- CORS: wildcard origin, `Content-Type` header.

### Obsidian plugin: `aditya30103/obsidian-contentdeck`

New repo at https://github.com/aditya30103/obsidian-contentdeck

**Plugin settings (data.json):**
- `supabaseUrl` — ContentDeck Supabase project URL
- `apiToken` — plaintext token from ContentDeck Settings → API Tokens
- `vaultFolder` — destination folder inside vault (default: `ContentDeck`)

**Sync flow:**
1. GET `sync-done?token=…` → list of done+unsynced bookmarks
2. For each bookmark: ensure `{vaultFolder}/{sourceFolder}/` exists, write `{title}.md`
3. POST `sync-done?token=…` `{ ids }` → mark synced
4. Notice "Synced N bookmarks from ContentDeck ✓"

**Source folders:**
- youtube → Videos, twitter → Threads, linkedin → LinkedIn
- substack/blog → Articles, book → Books, arxiv → Papers

**`generateMarkdown`** is ported from `src/lib/obsidian.ts` with all helpers inlined
(`yamlEscape`, `formatDate`, `getDomain`, `isBookWithoutUrl`, `SOURCE_LABELS`,
`getSourceFolder`, `safeFilename`). Produces identical output to Phase A.

## Installation (BRAT — no community store required)

1. Install BRAT plugin in Obsidian
2. "Add Beta Plugin" → `aditya30103/obsidian-contentdeck`
3. BRAT installs from GitHub release assets (`main.js`, `manifest.json`, `styles.css`)
4. Settings → ContentDeck Sync → paste Supabase URL + API token

## Deploy commands

```bash

npx supabase functions deploy sync-done --no-verify-jwt

# Test GET
```
