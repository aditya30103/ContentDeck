# v3.2 — Bookmarklet Deduplication Fix

**Issue:** #27 (user feedback — duplicate bookmarks from double-clicking bookmarklet)
**Commit:** `ff6cc53`
**Date:** 2026-02-26

---

## Problem

Double-clicking the bookmarklet (or re-running an iOS Shortcut for the same URL) would insert a second identical bookmark. The `save-bookmark` edge function had no deduplication check.

## Fix

Added a pre-insert deduplication query in `supabase/functions/save-bookmark/index.ts`:

1. After token validation, query `bookmarks` for an existing row matching `user_id` + `url`.
2. If found, return `{ id, status: 'already_saved' }` with HTTP 201 — silent, no error.
3. If not found, proceed with normal insert.

```ts
const { data: existing } = await adminClient
  .from('bookmarks')
  .select('id')
  .eq('user_id', tokenRow.user_id)
  .eq('url', url)
  .maybeSingle();

if (existing) {
  return jsonResponse({ id: existing.id, status: 'already_saved' }, 201);
}
```
