## What shipped

### fix/48-onboarding-empty-areas (Issue #48)
Values onboarding modal now gated on `areas.length > 0` via `useEffect`. Previously fired immediately for all new users regardless of whether they had any Tag Areas — creating a confusing dead-end experience where the modal asked users to prioritize areas that didn't exist yet.

**Files:** `src/pages/HomePage.tsx`, `src/components/__tests__/HomePage.test.tsx`

### feat/perf-code-splitting-sw-timeout

#### Vendor chunk splitting (`vite.config.ts`)
Added `manualChunks` for four vendor groups: `vendor-react`, `vendor-supabase`, `vendor-query`, `vendor-sentry`. These chunks carry immutable cache headers via `vercel.json` — on repeat visits they serve from browser cache even across app deploys.

#### Route-level lazy loading (`src/App.tsx`)
All three route components (`AuthScreen`, `Dashboard`, `HomePage`) converted to `React.lazy` + `Suspense`. `LoadingSpinner` component extracted (uses existing `Spinner` SVG component). Inline auth-loading spinner unified.

#### Sentry deferred init (`src/main.tsx`, `src/components/ui/ErrorBoundary.tsx`)
Removed static `import * as Sentry from '@sentry/react'` from both entry-point files. `main.tsx` now dynamic-imports Sentry after `createRoot().render()`. `ErrorBoundary.componentDidCatch` uses dynamic import on demand. Removes 46KB gzipped from the critical JS path.

#### SW navigation timeout (`public/sw.js`)
Navigation handler replaced with 4s `AbortController` timeout. Falls back to cached HTML on timeout/error. Eliminates Safari iOS "server stopped responding" hangs on Vercel cold starts. Removed unconstrained retry fetch (bug: could hang indefinitely on bad connections after already waiting 4s).

## Key decisions

- **Sentry deferred not skipped:** Dynamic import after render keeps vendor-sentry out of critical path while ensuring Sentry initializes before any user interaction/errors.
- **SW retry removed:** Unconstrained retry was a correctness bug on bad connections. Simpler: timeout → cached HTML → 503.
- **lucide-react NOT chunked:** Vite tree-shakes it per-route naturally; manual chunking would merge all icons into one file and undo the savings.
- **`LoadingSpinner` uses `Spinner`:** Reused existing SVG component (`src/components/ui/Spinner.tsx`) with proper `aria-hidden` and theme-aware colors.

## Post-ship fixes (same session)

### PR #54 — SW Safari fix
Replaced `AbortController` with `Promise.race` in the navigation handler. iOS Safari's service worker implementation does not reliably reject fetch promises on `controller.abort()` — the `catch` block silently never fires, leaving the page hanging. `Promise.race([networkFetch, timeout])` is fully Safari-compatible. Timeout increased 4s → 8s.

Confirmed fixed on iPhone 15 Safari after deploy.

### Direct commit — bypass `/_vercel/*` in SW
Added `url.includes('/_vercel/')` to the SW API bypass list. Vercel Analytics and Speed Insights POST to `/_vercel/insights/view` and `/_vercel/speed-insights/vitals` — these should never be intercepted or cached by the SW.
