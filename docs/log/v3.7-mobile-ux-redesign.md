## Summary

Two-track mobile UX overhaul: iOS/Android layout rendering fixes (Track 1) + Framer Motion gesture primitives (Track 2).

**Problem:** ContentDeck's mobile experience had layout overflow on iPhone 15, iOS Safari viewport reflow, body rubber-band scrolling, input auto-zoom, and zero gesture primitives.

## Track 1 — Layout & Rendering Fixes

- **CSS foundation** (`src/index.css`): `height: 100dvh; overflow: hidden` on `html`/`body`; `overscroll-behavior: none` on `body`; `font-size: max(16px, 1rem)` floor on all form inputs
- **App.tsx**: Replaced `min-h-screen` with `min-h-[100dvh]`
- **AppShell**: Added `overscrollBehavior: 'contain'` to `<main>` scroll container
- **MobileHeader**: Reduced from 6 buttons to 3 (Search, Settings, Add) — fixes 390px overflow on iPhone 15. Stats, Feedback, and Theme remain accessible via Settings modal.
- **HomePage**: Applied `min-h-[100dvh]`, `overflow-y-auto`, `overscrollBehavior: 'contain'`
- **Input audit**: `text-sm` → `text-base` on `TagAreaInput`, `SortSelect`, `FeedbackList` form elements

## Track 2 — Framer Motion Gestures

- **Framer Motion installed** (`npm install framer-motion`, ~12KB gzip)
- **usePullToRefresh** (`src/hooks/usePullToRefresh.ts`): Touch gesture hook with 64px threshold, resistance curve, spring reset. Returns `{ pullDistance: MotionValue<number>, isPulling, isRefreshing }`. Wired into AppShell with pull indicator UI; Dashboard invalidates TanStack Query cache on refresh.
- **DetailPanel draggable bottom sheet**: Replaced CSS `slideUp` animation with Framer Motion `drag="y"`, `dragConstraints`, spring dismiss (40% height OR velocity > 500px/s), animated backdrop via `useTransform`, drag handle pill, `AnimatePresence` for mount/unmount.
- **Modal drag-to-dismiss** (`src/components/ui/Modal.tsx`): All modals inherit `AnimatePresence` + `motion.div` slide-up enter/exit + drag-to-dismiss (>150px or >500px/s). Removed `document.body.style.overflow` side effect (globally locked in CSS now). Desktop layout preserved via `lg:` overrides.
- **ReaderModal swipe-to-close**: `drag="x"` + `dragDirectionLock` + `useTransform` opacity fade. Swipe right ≥ 80px or velocity ≥ 400px/s → close.
- **Route transitions** (`src/App.tsx`): `AnimatePresence mode="wait"` + `useLocation` key drives 0.2s fade+slide between Home ↔ Library.
