### Phase 2.5 — Spaced Review (SM-2 algorithm)

- Review card integrated into `HomePage.tsx` secondary card grid

### Bug Fix #42 — ReflectionModal no Cancel/Go Back button

- Root cause: `<Modal onClose={handleSkip}>` wired all dismiss paths (X, ESC, backdrop) to the skip mutation
- Fix: added `onCancel` prop to `ReflectionModal`; `Modal onClose={onCancel}` — no mutations fire on cancel
- Added "← Go back" button in footer (left side); "Skip for now" and "Save & Done" stay on right
- 2 new tests in `ReflectionModal.test.tsx`

### Bug Fix #43 — "Skip for now" appeared to save a note

- Root cause: `handleReflectionSave` in `HomePage.tsx` called `Promise.all([addNote.mutateAsync, cycleStatus.mutateAsync])` with no `try/finally`. If `addNote` succeeded but `cycleStatus` threw, `setPendingDoneBookmark(null)` was never called — modal stayed stuck open. User then clicked "Skip for now" → `cycleStatus` fired → note from failed Save attempt was already in DB, appearing as "saved by Skip".
- Fix: wrapped `Promise.all` in `try/finally`; `setPendingDoneBookmark(null)` always runs regardless of mutation outcome
- 1 new test in `HomePage.test.tsx`

### Bug Fix #38 — YouTube content_status='skipped' hides Read button with no feedback

- Root cause: `content_status === 'skipped'` (set when transcript extraction finds no captions) caused the entire extract/read button area to be hidden — no user-visible indication of why
- Fix: added inline `"No transcript available"` message in `MetadataHeader.tsx` for `skipped` + `youtube` combination

## Key decisions

- **SM-2 variant**: doubles on "still resonates", resets to 3 on "lost the thread" (no ease factor — simpler and appropriate for article-level content not flashcard-level facts)
- **No new DB columns for review state**: `review_interval` and `review_repetitions` stored in existing `metadata` JSONB — JSONB accepts arbitrary new keys, no migration needed for these fields
- **`last_reviewed_at` optional in Bookmark interface**: made `last_reviewed_at?: string | null` (optional) to avoid updating all 15+ test fixtures that use `makeBookmark` helpers
- **Review card grid logic**: Continue card always takes the left secondary slot; Review fills the right slot only when `continueItem` is present; avoids a layout hole when only one secondary card exists
