## What shipped

Three features that close the content loop entirely on the home screen:

### 1. Just Added strip
A compact full-width card (emerald accent) showing the most recently saved unread bookmark when it **wasn't already picked as the primary recommendation**. Serves explicit opening intent: "I just saved this — I'm here to read it."

- Rendered below the secondary grid, above MoodSelector
- Disappears when the newest unread bookmark is already the primary pick (deduplication via ID comparison)
- Tapping opens the URL and marks reading (same `handleStartReading` handler)
- Computed via `useMemo` on `bookmarks + topPick` — zero hook changes

### 2. Mark Done on Continue card
A "Mark done ✓" text action rendered inside the Continue secondary card. Triggers the Reflection Prompt rather than marking done directly.

- `e.stopPropagation()` prevents the card's outer click (open URL) from firing
- Only appears on `type === 'continue'` cards, only when `onMarkDone` prop is passed
- `aria-label` added to the outer `<div role="button">` card to prevent accessible name conflicts with the nested button

### 3. Reflection Prompt modal
Triggered before status changes to `done`. Voice (Web Speech API, Chrome/Android) + text textarea. "Save & Done" or "Skip for now".

- Voice gracefully absent on Firefox/Safari (jsdom + most browsers) — module-level `speechSupported` constant
- Voice appends to existing text rather than replacing it
- Save & Done: fires `addNote.mutateAsync` (reflection note) and `cycleStatus.mutateAsync` (→ done) in `Promise.all` — parallel independent DB writes
- Skip: `cycleStatus.mutate` only, no note
- Auto-Obsidian export fires via existing `cycleStatus.onSuccess` hook — zero changes needed
- State (`text`, `isListening`) resets on modal open and on close
- Recognition aborted on modal close if still listening

## Key decisions

**No DB migration** — `NoteType` union type already included `'reflection'` from Phase 2.3 planning. JSONB `notes` column accepts any NoteType without schema changes.

**No hook changes** — `addNote` and `cycleStatus` are already returned from `useBookmarks()`. Just added `mutateAsync` calls alongside the existing `mutate` API.

**Parallel DB writes** — `addNote.mutateAsync` and `cycleStatus.mutateAsync` run in `Promise.all`. They're independent writes (notes JSONB vs status column), so there's no ordering dependency.

**Voice typed locally** — Web Speech API is not in TypeScript's DOM lib. Defined minimal `SpeechRecognitionLike` interface locally rather than pulling in a third-party types package. `getSpeechRecognitionCtor()` function uses `window as unknown as Record<string, unknown>` pattern to safely access the vendor-prefixed API.

**`aria-label` on SecondaryCard** — the outer `<div role="button">` card was getting its accessible name from all text content (including the nested "Mark done ✓" button text), causing `getByRole('button', { name: /mark done/i })` in tests to find 2 elements. Added explicit `aria-label="Continue reading: {title}"` to override computed name. Also improves real screen reader experience.

**`speechSupported` is module-level** — evaluated once at import time. In jsdom (tests) and Firefox/Safari, both `SpeechRecognition` and `webkitSpeechRecognition` are absent, so the voice button is never rendered. Test 6 verifies this path. The "with API defined" path is not unit-testable without module isolation since the const is frozen after first import.

**JustAdded strip, not a 3rd secondary card** — distinct layout (full-width, below grid, emerald accent). A 3rd card in the grid would widen to fill on mobile and crowd the layout. Strip pattern is cleaner, distinct from the scoring-surfaced cards.

## Complete loop (Phase 2 milestone)

```
CAPTURE → SURFACE   → CONSUME      → REFLECT         → EXPORT
           |              |              |                 |
     [Primary Pick]  [Start Reading  [Mark Done ✓     [Auto-export
     [Just Added]    opens URL,      on Continue card  to Obsidian
     [Continue]      marks reading]  → Reflection      if configured]
                                      Modal saves
                                      reflection note]
```

The home screen now handles the complete session lifecycle without requiring a trip to the Library.
