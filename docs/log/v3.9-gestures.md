### Shared utilities

- `SHEET_DISMISS_FRACTION = 0.4` (40% of sheet height)
- `SHEET_DISMISS_VELOCITY = 500` (px/s flick threshold)
- `SWIPE_DISMISS_OFFSET = 80` (px horizontal)
- `SWIPE_DISMISS_VELOCITY = 400` (px/s horizontal)

**`src/hooks/useIsMobile.ts`** — `matchMedia('(max-width: 639px)')`, same pattern as `useTheme.ts`. Used to gate `drag` and variant selection in Modal.tsx.

### DetailPanel — draggable bottom sheet + desktop fade

**Mobile:**
- Converted to `motion.div` with `initial={{ y: '100%' }} animate={{ y: 0 }} exit={{ y: '100%' }}`
- Backdrop fades in/out; `useMotionValue` + `useTransform` links drag offset to live backdrop opacity
- **Drag handle pill** at top of sheet: `w-10 h-1 rounded-full bg-surface-300`
- Drag-to-dismiss: `drag="y" dragConstraints={{ top: 0 }} dragElastic={0.1}`
  - Dismiss if `offset.y > sheetHeight * 0.4` OR `velocity.y > 500px/s`
  - Otherwise springs back to rest
- `useReducedMotion()` → `duration: 0` when active

**Desktop:**
- `<motion.aside>` with `initial={{ opacity: 0, x: 20 }} animate={{ opacity: 1, x: 0 }} exit={{ opacity: 0, x: 20 }}`
- Transition: `duration: 0.15` (quick, non-intrusive)
- No drag

**Dashboard.tsx:**
- Wrapped DetailPanel render in `<AnimatePresence>` with `key={activeBookmark.id}`
- Removed `if (!bookmark) return null` guard — AnimatePresence controls mount/unmount

### Modal.tsx — AnimatePresence + mobile drag-to-dismiss

Upgraded all 8 modals that use Modal.tsx (Add, Edit, Settings, Stats, Feedback, Reflection, Review, ValuesOnboarding).

- Always renders `<AnimatePresence>` — moved `if (!open) return null` inside
- Removed broken `motion-safe:animate-[slideUp_0.2s_ease-out]` CSS reference (keyframe never existed)
- **Backdrop**: `motion.div` with opacity fade
- **Dialog panel**: `motion.div` with variant sets based on `useIsMobile()`:
  - Mobile: `initial={{ y: '100%' }} animate={{ y: 0 }} exit={{ y: '100%' }}` + `drag="y"` dismiss

- **Drag handle pill** on mobile modals
- Drag-to-dismiss: same thresholds as DetailPanel
- Preserved: focus trap, ESC handler, backdrop click, body scroll lock, safe area padding

### ReaderModal — horizontal swipe-to-dismiss

- Outermost container → `motion.div`
- `initial={{ x: '100%' }} animate={{ x: 0 }} exit={{ x: '100%' }}` — slides in from right (iOS push nav feel)
- `drag="x" dragDirectionLock` — framer-motion locks to the primary gesture axis. If the user starts scrolling vertically, horizontal drag is suppressed; if they start swiping horizontally, vertical scroll is suppressed.
- `dragElastic={{ left: 0.05, right: 0.3 }}` — rightward feels elastic (dismiss direction), leftward feels stiff
- Dismiss: `offset.x > 80px` OR `velocity.x > 400px/s` (rightward only)
- On dismiss: calls `onClose()` + `history.back()` if `history.state.reader` exists (cleans up the pushed entry)
- `AnimatePresence` wrapper moved to `DetailPanel.tsx` call site
- Removed `if (!open) return null` guard — AnimatePresence controls mount/unmount

## Key decisions

- **`dragDirectionLock` on ReaderModal** — prevents horizontal swipe fighting vertical scroll. framer-motion determines axis from first few pixels of touch and locks to it. This is the correct native pattern.
- **No live backdrop-drag link on Modal.tsx** — Modal.tsx doesn't need `useMotionValue` backdrop linking; the simpler fade in/out on AnimatePresence is sufficient since modals aren't as drag-heavy as the detail sheet.
- **Route transitions deferred** — only 2 routes, and `AnimatePresence` + `Suspense` interaction adds complexity for minimal UX gain. Revisit if more routes are added.
- **Pull-to-refresh deferred** — requires `usePullToRefresh` hook with `MotionValue<number>` return type; worth a dedicated session.
- **Card swipe actions deferred** — swipe-left/right on bookmark cards for quick actions. Significant per-card complexity; evaluate after further production use.
- **`useReducedMotion()` throughout** — all spring transitions collapse to `duration: 0` when the user has enabled reduced motion in OS settings. CSS `prefers-reduced-motion` media query in `index.css` remains as belt-and-suspenders.
